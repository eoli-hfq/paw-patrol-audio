# 汪汪队音频文案生成技能

一个用于生成 **汪汪队（PAW Patrol）** 音频/语音文案的技能。根据用户给出的主题
（生日、上幼儿园、好好吃饭、睡觉、比赛加油等），按固定样式输出包含音色描述、
背景音效、停顿节奏、台词与结尾音效的完整配音稿。

## 一、功能概述

技能支持两种生成模式：

- **全角色模式**：按固定出场顺序，每个成员各说 1–3 句，末尾全体合体收尾。
- **单角色模式**：指定 1 位角色，围绕主题独立生成完整一段（约 3–5 句）。

主角名默认 **诺诺**，可在指定后于全文替换，句式保持不变。

## 二、使用方式（推荐工作流）

本技能的典型使用流程：

1. **生成文案**：描述主题（生日 / 上幼儿园 / 好好吃饭 / 睡觉等）与主角，触发本技能，得到含音色描述、背景音效、台词、停顿节奏与结尾音效的完整配音稿。
2. **润色**：打开火山方舟的音频生成功能，将文案粘贴进去，按需稍加润色。
3. **生成音频**：用方舟合成音频，用来鼓励诺诺小朋友。
4. **备选**：也可通过方舟 CLI 调用完成合成。

> 主要用途：把每天的鼓励（按时上幼儿园、好好吃饭、乖乖睡觉、生日祝福等）做成汪汪队语音，用孩子熟悉的角色声音陪伴、鼓励诺诺小朋友。

## 三、角色库概览

默认全角色出场顺序：

> 莱德(开场) → 阿奇 → 毛毛 → 天天 → 小砾 → 灰灰 → 路马 → 珠珠 → 小克 → 全体(合体收尾)

| 角色 | 救援类型 | 定位 |
|------|----------|------|
| 莱德 | 队长 | 开场号召、下达指令、宣布好消息 |
| 阿奇 | 警察 | 播报、表扬、宣布 |
| 毛毛 | 消防 | 热情打气、暖心关怀 |
| 天天 | 空中救援 | 甜甜祝福、轻盈鼓励 |
| 小砾 | 建筑 | 发现惊喜、骄傲自豪、力量感 |
| 灰灰 | 回收环保 | 俏皮创意、机灵 |
| 路马 | 水上救援 | 爽朗随性、帅气鼓励 |
| 珠珠 | 雪地救援 | 爽朗祝福、清亮 |
| 小克 | 丛林救援 | 机敏俏皮、探险鼓励 |
| 全体队员 | — | 经典台词收尾、齐声加油 |

> 每位角色的完整音色描述与背景音效原句见 [`SKILL.md`](SKILL.md) 第二节，生成时直接复用。

## 四、输出格式模板

每位角色（或每段）按以下结构输出；「定位」行为非必需，默认省略：

```
[角色名] 是[音色描述]

背景[背景音效描述]。
[角色名][动作描写]，[语气描述]："[台词]"
[角色名][停顿词]，[语气变化]，[动作描写]："[台词]"
结尾[音效句]。
```

规则：

1. 音色描述与背景音效描述直接复用角色库原句，除音色外不加"（定位）"标题行。
2. 每句台词用中文双引号包裹，前面标注说话者、动作描写与语气/停顿。
3. 停顿词按序交替使用：稍作停顿 → 稍微停顿 → 再次稍作停顿 → 第三次稍作停顿；同一词不得连续出现两次。
4. 语气需有变化（坚定→温柔→上扬→兴奋→收尾），避免平淡。
5. 全角色 / 多角色模式：角色切换时另起一段并写"背景切换为……"；莱德开头喊集合，最后"全体队员"用经典台词收尾。
6. 单角色模式：该角色独立成段，结尾补上任一结尾音效句。

## 五、经典台词与结尾音效

经典台词：

> `没有困难的工作，只有勇敢的[名字]！`
> （原名版本：没有困难的工作，只有勇敢的狗狗！）

结尾音效从以下 4 个变体中选 1 句，同一篇内保持同一变体、不混用：

- **标准版**：结尾配上汪汪队胜利号角的短促音效，和主题音乐一起渐渐淡去。
- **卡通版**：结尾配上一声清脆的卡通小狗欢呼汪叫的音效，和轻快的主题音乐一起渐渐淡去。
- **短促版**：结尾响起一声短促的汪汪队胜利号角小音效。
- **渐强版（小队 / 日常场景）**：结尾的卡通背景音乐音量稍稍抬高，伴着几声小家伙们欢快的汪汪叫，氛围暖融融的满是元气。

## 六、生成流程

🔴 检查点（满足任一条即暂停等用户回答后再继续；都不满足则直接执行，不打断）：

- 模式不明：用户未说明是「全角色」还是「某一位角色」；
- 主题不明：用户未给出可归类的主题；
- 角色越界：用户点名的角色不在角色库名单内。

1. **定模式**：用户未指定则默认全角色；点名单一角色则用单角色模式。
2. **定主题与主角名**：得到可归类的主题标签 + 主角名（默认"诺诺"）。
3. **排台词**：全角色每人 1–3 句、单角色 3–5 句。
4. **补场景**：每句前置动作描写、语气、停顿，段首写音色与背景。
5. **加收尾**：全角色加经典台词 + 任一句结尾音效。

## 七、可替换参数

| 参数 | 说明 |
|------|------|
| 主角名 | 默认"诺诺"；用户指定其他名字时全文替换，句式不变 |
| 主题 | 生日 / 上幼儿园 / 好好吃饭 / 睡觉 / 比赛加油 / 日常鼓励等 |
| 年龄 | 仅当用户给出年龄或明确要求生日祝福时，插入"X岁生日快乐" |

## 八、示例

### 单角色示例（阿奇 · 主题：主动上幼儿园）

> 阿奇 是活力满满的少年声线，阳光活泼，精神饱满，像汪汪队动画里的警员阿奇的播报音色，语速稍快，语气亲切有号召力。
>
> 背景搭配汪汪队主题明快活泼的管弦乐短旋律，间隙点缀几声俏皮的小狗叫音效，营造热闹喜悦的庆祝氛围。
> 阿奇带着十足的喜感，声音上扬，元气满满地开口播报："汪汪队播报！"
> 阿奇稍作停顿，笑意满满地继续："诺诺小朋友今天自己主动要去幼儿园，"
> 阿奇语气拔高，兴奋地喊道："你好棒啊，真勇敢！"
> 结尾配上汪汪队胜利号角的短促音效，和主题音乐一起渐渐淡去。

更多完整案例见 [`references/audio-cases.md`](references/audio-cases.md)。
